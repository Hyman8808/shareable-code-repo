# 阿拉伯语支持 — 交付与验收说明

**版本**：v2.11.3（versionCode 48）
**日期**：2026-10-27
**包**：`单词卡相机_v2.11.3_debug.apk` / `单词卡相机AI_v2.11.3_debug.apk`

---

## 一、结论先说

**v2.11.2 及更早的测试包里没有阿拉伯语。** 本次从零开发，v2.11.3 起支持。

核查方式与结果：

| 检查项 | v2.11.2 实况 | 说明 |
|---|---|---|
| `values-ar/` 目录 | **不存在** | 项目自有资源只有 `values`（中）、`values-en`、`values-zh-rTW` |
| APK 内 `(ar)` 资源 | 105 条 | **全部来自 Material / AppCompat 库**，如 `password_toggle_content_description`、`character_counter_*`；自有 437 条文案 0 条阿语 |
| 界面语言档位 | 3 档（中 / 繁 / 英） | 无阿语入口 |
| 物品名称语言 | 9 项 | 无 `ar` |
| `app_name` 阿语 | 无 | 阿语系统下桌面图标显示中文 |

> 为什么容易误判：`app/build/intermediates/.../merged.dir/values-ar/` 确实存在，但那是依赖库合并进来的产物，不是我们的文案。只看这个目录会得出「有阿语」的错误结论。

## 二、怎么验证（3 步）

### 步骤 1：切成阿语界面

`我的` → `界面语言` → 点 **العربية**

弹出层现在有 4 项，阿语排第 4：

| 顺序 | 显示名 | 副标题（内容随当前界面语言变） |
|---|---|---|
| ① | 中文（简体） | 默认 · 简体中文界面 |
| ② | 中文（繁體） | 繁体中文界面 |
| ③ | English | 英语界面 |
| ④ | **العربية** | 阿拉伯语界面（从右到左） |

选中后**整屏立即翻转成 RTL**（不是重启才生效）。验证点：

- 底部 Tab 顺序镜像：「السجلات / المحفوظات / الأجهزة / حسابي」，图标与文字右对齐
- 返回箭头方向正确（指右，不是指左）
- 列表分隔线贴右边
- `‹` / `›` 这类箭头全部朝左（RTL 方向）

### 步骤 2：切成阿语名称语言

`我的` → `物品名称语言` → 点 **العربية**（列表第 10 项，排最后）

### 步骤 3：验证设备语言（可选，需连设备）

`我的` → `设备语言` 同样出现 **العربية**。选择后下次连设备会自动下发 `0x12 / 0x10 ITEM_LANG = "ar"`。

## 四、依赖外部的事项（不在 App 交付范围）

App 侧已全部打通并按协议原样下发，下面三项任一未就绪都**不需要再改 App 版本**，但会让阿语体验不完整。

### 1. 云端 `name_localized` 的 `ar` 通道

- App 行为：名称语言选阿语后，同步请求带 `lang=ar`，期待返回 `name_localized`。
- 未就绪时的表现：**回退显示中文原词**，并在详情页提示「暂未收录阿语名称」——不会崩、不会伪造译名。
- 待确认：正式版《云端接口协议 V2.1》的 `lang` 白名单里是否已含 `ar`。

### 2. 固件 `0x10 ITEM_LANG` 的 `ar` 资源

- App 行为：配网时下发 `ITEM_LANG="ar"`、`UI_LANG="ar"`。
- 未就绪时的表现：设备端提示语仍是原语言（通常英文），App 侧不受影响。
- 待确认：固件是否为 `ar` 准备了提示语资源；无则设备端需按英文兜底。

### 3. `ar-SA` TTS 发音

- 研发此前声称 cosyvoice-v2 跨语言音色支持 `ar-SA`，但**我方尚未抽样试听**（造测试数据会污染 prod，需先有删除接口）。
- 建议：在客户演示前抽 3~5 条卡实际听一遍，确认不是英文音色硬读阿语文本。

## 五、RTL 适配说明（阿语不只是翻译）

阿语从右往左读，Android 会按 locale 自动镜像整个布局。本次逐项核对：

| 检查项 | 结论 |
|---|---|
| `android:supportsRtl` | Manifest 早已为 `true`，无需改 |
| 布局物理方向属性（`layout_marginLeft` / `layout_toRightOf` / `paddingLeft`…） | **0 处**，全部 `Start/End`，自动镜像 |
| 方向性图标（返回、右箭头） | 3 个补 `android:autoMirrored="true"`，否则阿语下箭头指反 |
| 文本内方向符号 | `›` 阿语下写 `‹`；`→` 写 `←`；`common_back` 去掉箭头只留「رجوع」 |
| 翻页手势 | 自定义触摸实现、未用 ViewPager2 ⇒ 不受 RTL 索引反转影响 |
| SSID / 密码输入框 | 保持系统默认：RTL 下右对齐，符合阿语书写习惯 |
| 数字与价格 | 阿语用西方数字，`%1$d / %2$d` 与 `%1$d ¥` 已按阿语语序排列 |

## 六、已知边界

1. **Android 13+ 系统设置里的「应用语言」未启用。** 当前只支持 App 内切换（`我的 › 界面语言`）。若要系统级入口，需补 `android:localeConfig`（可后续加，不影响本次演示）。
2. **阿语界面里的语言名用英文写**（Arabic / Japanese…），不用中文。原因：中文对阿语用户完全不可读。中文界面下仍显示中文名。
3. **未做真机验证**（构建机无连接设备）。已完成的静态校验：四档 locale 正确进包、`application-label-ar` 正确、阿语 543 条资源、占位符 0 错配、`\n` 无丢失、dex 关键类完整。
